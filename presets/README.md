# calibrick slicer presets

A calibration profile is only valid for the exact slicer process it was measured with.
These are the **locked process presets** that calibration coupons and parts must be
sliced with. They are generated by `calibrick.slicer.bambu.write_process_preset()`.

| File | Printer | Inherits from |
|---|---|---|
| `calibrick 0.20mm @BBL A1M.json` | Bambu Lab A1 mini, 0.4 nozzle | `0.20mm Standard @BBL A1M` |
| `calibrick 0.20mm @BBL P1P.json` | Bambu Lab P1P, 0.4 nozzle | `0.20mm Standard @BBL P1P` |

## Import into Bambu Studio

1. Select the printer first: **Bambu Lab A1 mini 0.4 nozzle** (or **Bambu Lab P1P 0.4 nozzle**).
   The preset inherits from that printer's stock `0.20mm Standard` preset; if the printer
   is not added in Studio the import is silently skipped.
2. **File > Import > Import Configs...** and pick the JSON file for your printer.
3. In the **Process** dropdown choose `calibrick 0.20mm @BBL A1M` (it appears under the
   user presets).
4. **Filament:** use your normal preset for the spool (for example `Bambu PLA Basic @BBL A1M`)
   and leave it untouched. Keep *Flow dynamics calibration* ticked when you send the print.
5. Spot-check five values in the process settings: Layer height 0.2, Initial layer
   height 0.2, Wall loops 6, Order of walls outer/inner, Outer wall speed 40.

Keep these the same between the calibration print and the real parts, because they are
part of what was calibrated: the process preset, the filament preset, and the build plate
type (smooth and textured plates squash the first layer differently).

OrcaSlicer uses the same preset format and the same stock preset names, so the same
import should work there; it has only been checked against Bambu Studio's profile
definitions (master, profile version 02.09). If the import fails, use the table below.

Left at the stock value on purpose: line widths, arc fitting, travel speeds, infill and
bridge speeds, cooling (cooling lives in the filament preset).

## Why these values

- **0.2 mm layers with the stock 0.2 mm first layer**: every brick height is a whole number of
  layers (plate 3.2 mm = 16, brick 9.6 mm = 48, stud 1.8 mm = 9). A thinner first layer was
  tried and did not lay down on textured PEI.
- **X-Y compensation at 0**: calibrick puts the size corrections into the geometry,
  per feature. A slicer-wide offset on top would double-correct.
- **Outer wall first, slow, low acceleration**: the outer wall is laid down against
  nothing, so its position does not depend on how much the inner walls pushed outward.
- **Small perimeter threshold 4 mm**: studs, underside tubes and stud sockets all have a
  radius below 4 mm, so they print at 20 mm/s.
- **6 wall loops**: studs and the 1.5 mm brick walls are made of perimeters only.
- **Scarf seam on contours**: spreads the seam on round studs instead of leaving one bump.
  Holes keep a normal seam.
- **No brim, no supports**: both change the footprint that the calibration measured.

## Regenerating

```python
from pathlib import Path
from calibrick.profile import Profile
from calibrick.printers import get_printer
from calibrick.slicer.bambu import write_process_preset

write_process_preset(Profile(), get_printer("a1mini"), Path("presets"))
# options: scarf_seam=False, elephant_foot=0.1
```
